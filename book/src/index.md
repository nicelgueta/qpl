# qpl — Quick Polars Query Language

An agent-friendly, q/kdb+-inspired query language that compiles to Polars lazy
frames. Write concise select statements; Polars runs them fast. Single binary,
zero dependencies — no Python, no Polars install needed.

There's also a [VSCode extension](https://github.com/nicelgueta/qpl/tree/main/tools/vscode) —
syntax highlighting plus a Ctrl+Enter REPL for sending lines straight from the
editor.

Source, issues, and releases live on
[GitHub](https://github.com/nicelgueta/qpl).

See [Why?](why.md) for the motivation, or jump straight to
[Install](install.md) and [Quickstart](quickstart.md).
