# Language

The chapters in this part build on each other in order. The early ones are
small and cover things you'll use in literally every statement you write:
comments, binding names, symbols. From there the book works through the query
statements themselves, then the expression vocabulary that goes inside them,
and finally the more specialised corners — user-defined functions, lazy
pipelines, organising code into scripts and namespaced imports, and talking
to another qpl process over a socket.

If you're reading straight through, just carry on. If you're looking
something up, the sidebar is the index and
[Operator reference](operator-reference.md) at the end lists every operator in
a single table with a pointer to the chapter that explains it.
